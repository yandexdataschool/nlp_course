# Перевод курса ШАД NLP на русский

## Что уже переведено в этом архиве

Вручную переведены главный `README.ru.md` и README для восьми доступных недель (`week01_embeddings` — `week08_finetuning`). Ссылки на лекции, упражнения и дополнительные источники сохранены. В архив **не входят** оригинальные Jupyter Notebook, PDF, данные или видео: их надо взять из [оригинального репозитория](https://github.com/yandexdataschool/nlp_course).

## Локальный перевод ноутбуков и других Markdown-файлов

### 1. Скачайте исходный курс

**Основной ПК (Arch Linux):**

```bash
git clone --depth 1 --branch 2026 https://github.com/yandexdataschool/nlp_course.git
cd nlp_course
```

### 2. Распакуйте этот архив в корень клонированного репозитория

Переведённые `README.ru.md` должны оказаться рядом с английскими `README.md`, а `translate.py` — в корне репозитория. Уже переведённые вручную README скрипт повторно не обрабатывает по умолчанию.

### 3. Запустите Ollama

**Основной ПК:**

```bash
ollama pull qwen3:8b
ollama serve
```

Если Ollama уже работает как сервис, повторный `ollama serve` не требуется.

### 4. Переведите первую неделю

**Основной ПК, из каталога `nlp_course`:**

```bash
uv run translate.py --root . --only week01_embeddings --dry-run
uv run translate.py --root . --only week01_embeddings
```

Появятся файлы `seminar.ru.ipynb` и `homework.ru.ipynb`. Их можно открывать в Jupyter/VS Code и выполнять как оригиналы.

### 5. Переведите остальные недели

```bash
uv run translate.py --root .
```

Для перевода извлекаемого текста англоязычных PDF-слайдов **в отдельные Markdown-документы**:

```bash
uv sync --extra pdf
uv run --extra pdf translate.py --root . --pdf-text
```

Команда создаёт рядом с `lecture.pdf` файл `lecture.ru.md` с разбивкой по слайдам. Это не отредактированный PDF. Текст внутри изображений, диаграммы, математическую разметку и сложную вёрстку PDF необходимо сверять с оригиналом.

## Что сохраняется и что переводится

| Тип данных | Результат |
|---|---|
| `README.md` | Отдельный `README.ru.md`; восемь README уже переведены вручную |
| Markdown-ячейки `*.ipynb` | Перевод на русский с сохранением JSON-структуры |
| Кодовые ячейки `*.ipynb` | Без изменений, чтобы не нарушить выполнение |
| Выходные данные ноутбуков | Без изменений; могут оставаться английские подписи и сообщения |
| Другие Markdown | Перевод с защитой URL, inline-кода и формул |
| PDF | Опционально текстовая версия `*.ru.md`, не переразметка слайдов |
| Видео | Не скачиваются и не переводятся; часть лекций уже на русском |

## Ограничения

Автоматический перевод через локальную LLM может ошибаться в технических терминах, формулах и форматировании. Скрипт защищает ссылки, inline-код и формулы, но не гарантирует полную эквивалентность исходнику. Если модель повредила защищённые фрагменты, оригинал сохраняется в итоговом блоке, а предупреждение добавляется в `ПРОВЕРИТЬ_ПЕРЕВОД.txt`.

Текст в комментариях и docstring внутри **кодовых** ячеек оставлен на английском сознательно: автоматическая замена строк может нарушить тесты и работу программы. Встроенные в исходный курс графики и изображения тоже не переводятся автоматически.

При повторном запуске используются сохранённые результаты из `.ysda-translation-cache.jsonl`, а существующие `.ru.md` и `.ru.ipynb` пропускаются. Чтобы переработать конкретный файл, удалите его русскую версию; для полной принудительной обработки укажите `--force`.
